1. OVERVIEW OF IMPLEMENTATION & CHANGES
----------------------------------------------------------------------

Milestone 1: HTTP Download Checksum Verification
- Added `ChecksumOption` struct (Algorithm: md5/sha1/sha256, Expected: hex string) in pkg/base/model.go.
- Added optional `Checksum *ChecksumOption` (`json:"checksum,omitempty"`) to `base.Options`.
- Implemented streaming file checksum verification in `internal/protocol/http/fetcher.go` via `verifyChecksum()`.
  Zero memory overhead (streams directly from file on disk via 64KB buffer).
- Wired checksum verification into the completion pathways of HTTP fetcher. Fails gracefully with descriptive mismatch error if hash does not match, marking task as failed.
- Wired optional checksum fields into MCP `downloadOptions` and `pkg/rest/model/task.go`.

Milestone 2: New MCP Tool (get_download_speed)
- Implemented `get_download_speed` tool in `pkg/mcpserver/server.go`.
- Supports querying instantaneous download/upload speed, total/downloaded bytes, progress percentage, and ETA calculation for:
  a) A specific task ID.
  b) Global aggregate speed across all active running tasks when task ID is omitted.
- Registered in MCP tool registry with read-only annotations.

Milestone 3: Webhook Lifecycle Enhancements
- Added `WebhookEventDownloadPause` ("DOWNLOAD_PAUSE") event type in `pkg/download/webhook.go`.
- Triggered `DOWNLOAD_PAUSE` event on task pause in `pkg/download/downloader.go`.

Milestone 4: CLI Parity
- Added `-checksum` and `-checksum-algo` (default: md5) flags to `cmd/gopeed/flags.go`.
- Configured `cmd/gopeed/main.go` to construct `ChecksumOption` and pass it to download tasks.
