1. SUMMARY OF INTEGRATION
--------------------------------------------------------------------------------
The `TaskSpeedChart` widget (located at `ui/flutter/lib/app/views/task_speed_chart.dart`)
has been integrated into the task detail drawer within `TaskView`
(`ui/flutter/lib/app/modules/task/views/task_view.dart`).

Key Details:
- Wired to the per-task rolling speed buffer (`speedHistory` in `TaskListController`)
  looked up by the active task ID (`selectTask.value?.id`).
- Reactively updates via GetX `Obx` whenever new speed samples are recorded for
  the task.
- Cleanly scoped to only display speed metrics for the selected task.

3. PLACEMENT IN THE VIEW & RATIONALE
--------------------------------------------------------------------------------
- Placement: Located inside `TaskView`'s `endDrawer` (`DrawerHeader` -> `TaskSpeedChart` -> `taskName` ListTile -> `taskUrl` -> `downloadPath`).
- Rationale:
  1. Primary Task Detail Location: In Gopeed, clicking/tapping any task in the
     task list opens the `endDrawer` which displays `'taskDetail'.tr` (Task Details).
  2. Natural Information Hierarchy: Placing the speed chart at the top of the detail
     drawer immediately below the header gives users instant visual feedback on the
     live download speed before browsing static task metadata.
  3. Visual Consistency: Wrapped with `EdgeInsets.symmetric(horizontal: 16.0, vertical: 8.0)`
     to match the ListTile horizontal padding and drawer spacing used throughout
     the application.
