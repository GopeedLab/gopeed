SPEED CHART WIDGET IMPLEMENTATION REPORT

1. SUMMARY OF WHAT WAS BUILT
--------------------------------------------------------------------------------
A new, standalone, and isolated chart widget `TaskSpeedChart` was created for
rendering live download-speed-over-time data.

Key Features & Behavior:
- Accepts a `List<double> speedSamples` representing bytes/second data samples
  (matching the rolling buffer of ~60 samples from `TaskListController`).
- Renders a clean, smooth single-line speed curve with an optional subtle
  gradient fill beneath the line.
- Graceful Empty / Short Data Handling:
  * When `speedSamples` has fewer than 2 points, it renders a clean baseline
    or an optional custom `emptyPlaceholder` widget instead of failing or throwing.
- Reactive & Standalone:
  * Built as a self-contained `StatelessWidget` compatible with GetX's `Obx`
    reactive wrappers or direct parameter passing.
  * Respects theme colors (`Theme.of(context).colorScheme.primary`), stroke width,
    and styling conventions used throughout Gopeed.
  * Handles rapid data stream updates without memory leaks or UI glitches.


2. FILE PATH OF THE NEW WIDGET
--------------------------------------------------------------------------------

3. CHARTING LIBRARY USED & RATIONALE
--------------------------------------------------------------------------------
- Library Used: Flutter Native Custom Painting (`CustomPainter` / `Canvas`)
- Rationale:
  1. Zero Extra Dependencies: Flutter's native 2D canvas requires no third-party
     package additions or dependency version constraints, preventing lockfile/pub
     incompatibilities.
  2. High Performance: Ideal for high-frequency (1 Hz / 60 FPS) rolling streaming
     data with minimal memory overhead and zero garbage collection pressure.
  3. Precise Customization: Direct control over anti-aliasing, stroke joins/caps,
     bounding box scaling, and vertical gradient shaders.
  4. Platform Portability: Uniform rendering across Windows, macOS, Linux, Android,
     iOS, and Web targets supported by Gopeed.
